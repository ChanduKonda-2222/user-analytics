# Contributing

1. Do not develop directly on `main`.
2. Create a branch for your UI.
3. Keep HTML, CSS and JavaScript readable.
4. Test the page on desktop and mobile sizes.
5. Commit using a meaningful message.
6. Push your branch.
7. Open a Pull Request.
8. Review another member's Pull Request.
9. Make requested changes.
10. Merge only after approval.

## Example

```bash
git checkout -b member-1-analytics-overview
git add .
git commit -m "feat: add analytics overview templates"
git push origin member-1-analytics-overview
```
